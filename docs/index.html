Free open source tool

ticket-redact

Strip PII from exported support tickets and chat transcripts locally, so a file is safe to share for QA, training or AI tools without sending it to a third party service first.

View source on GitHub

What it does

  • Email addresses and international phone numbers, including country code formats
  • Credit cards validated with the Luhn check, so random order numbers are left alone
  • IBANs validated with the mod-97 check, plus IPv4 addresses with octet range validation
  • URLs starting with http or https
  • Consistent placeholders: the same value becomes the same placeholder across the whole file, and the report contains counts by type only, never raw values

Install and usage

Requires Node.js 20 or later. There are no dependencies to install.

git clone https://github.com/aamirtechs/ticket-redact.git
cd ticket-redact
node src/cli.js examples/tickets.csv redacted.csv --report report.md
node src/cli.js examples/tickets.json redacted.json --report report.md

Input and output formats are chosen by file extension, .csv or .json. The same value always becomes the same placeholder within one run, for example the first distinct email becomes a single numbered email placeholder everywhere it appears.
