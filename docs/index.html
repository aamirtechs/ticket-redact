Free open source tool

ticket-redact

Strip PII from exported support tickets and chat transcripts locally, so a file is safe to share for QA, training or AI tools without sending it to a third party service first.

View source on GitHub

Use it in your browser

Runs fully in your browser, files never leave your device. Drop a CSV or JSON ticket export below, or paste its contents. Emails, phone numbers, credit cards (Luhn checked), IBANs (mod-97 checked), IP addresses and URLs are replaced with consistent placeholders, and the report shows counts only, never raw values.

You can also drag and drop the file anywhere on this panel.
